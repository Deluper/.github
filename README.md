## Overview

This repository (`Deluper/.github`) is the central metadata and organization-level configuration repository for the **[Deluper](https://github.com/Deluper)** GitHub organization.

In accordance with GitHub's special repository conventions, `.github` serves as:
1. **The Public Organization Profile:** The [`profile/README.md`](profile/README.md) file is automatically rendered as the main landing profile for [github.com/Deluper](https://github.com/Deluper).
2. **Brand & Vector Asset Hub:** Houses official, production-ready vector graphics, high-resolution logos, banners, and theme assets under [`profile/assets/`](profile/assets/).
3. **Engineering Standards & Community Defaults:** Establishes organizational licensing, templates, and baseline conventions across all Deluper repositories.

## Organization Engineering Guidelines

Repositories maintained within the **Deluper** organization adhere to rigorous engineering standards:

### 1. Branching & Lifecycle Management
- **Default Branch:** `main` serves as the primary production-ready integration branch.
- **Feature Branches:** Use descriptive prefixes such as `feat/`, `fix/`, `docs/`, `refactor/`, or `perf/`.
- **Pull Requests:** All changes undergo validation, continuous integration checks, and review before merging.

### 2. Commit Message Standards
Commits follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
- `feat:` New features or capabilities
- `fix:` Bug fixes and error resolutions
- `docs:` Documentation improvements or profile updates
- `style:` Formatting, whitespace, and UI asset refinements
- `refactor:` Code restructuring without behavioral changes
- `perf:` Performance optimizations and latency reductions
- `chore:` Dependency maintenance, build tooling, and configuration

### 3. Security & Quality Assurance
- **Secret Protection:** Automated secret scanning and push protection are enforced. Never commit tokens, credentials, or private keys.
- **Dependency Auditing:** Automated scanning monitors dependencies for vulnerabilities.
- **Code Health:** Consistent linting, type-checking, and comprehensive test coverage across backend and frontend codebases.
